# MSI GF63 Thin 11SC Linux Fan Controller

Experimental automatic multi-stage fan controller for MSI GF63 Thin 11SC / MS-16R6 on Linux.

Fan stages:

- Auto
- 50%
- 75%
- 90%
- 100% Cooler Boost

> Warning: This project performs direct MSI Embedded Controller writes.

## Development

ChatGPT by OpenAI was used as an AI-assisted development tool for code structure, documentation, troubleshooting, and refinement.

Hardware behavior and EC register operation were tested on an MSI GF63 Thin 11SC / MS-16R6.
